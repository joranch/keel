What happens when you apply

  1. Keel re-reads each keyword and skips any whose bid changed since 06:04.
  2. Google checks the changes before they are made.
  3. The changes are sent, then read back to confirm.
  4. Rules leave these bids alone for 7 days so you can judge the effect.
  5. You can undo for 30 days from Recent changes.
Applied changes are listed under Changes, where each one can be undone for 30 days.
