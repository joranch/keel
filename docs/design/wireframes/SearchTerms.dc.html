How the verdict works

Expected conversions = clicks × each term's campaign conversion rate (2.9% here). Below 3, zero conversions can still be luck, so Keel says needs more data instead of suggesting a negative.

Negatives from n-grams are added as phrase match at campaign level, on Performance Max too (they apply to its Search and Shopping inventory). Keel warns if one would block a term that converts.
